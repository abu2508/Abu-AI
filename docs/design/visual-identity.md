# Abu AI visual identity: confirmed requirements

Status: **confirmed by the product owner; no app code exists yet.** This records the requirements the mobile
milestone must satisfy. It is not a design: tokens, assets and screens are produced in that milestone.

## Direction: Hybrid
- Premium minimalism in the spirit of Apple's design language, plus restrained futuristic-AI touches.
- Clean layouts, refined typography, subtle gradients, restrained motion.
- Intelligent visual feedback while Abu AI is processing, thinking or finishing a task.
- It must feel like a personal AI operating system: not a chatbot, not an admin dashboard.

## Appearance
- Default: follow the iPhone's system appearance, Light and Dark, switching live without a restart.
- Optional manual override in Settings (System / Light / Dark).
- Accessible contrast and readability in both themes (target WCAG AA; respect Dynamic Type and Reduce Motion).

## Visual language
- Uncluttered home dashboard.
- Distinct identities for Finance, Messaging and Daily Coach, inside one consistent system
  (icons, spacing, type scale, reusable components, navigation and interaction patterns).
- Subtle AI-activity indicators; smooth, not excessive, transitions.
- Elegant charts and financial visualisations.

## Abu AI identity
- Original identity for the app icon, splash screen, onboarding and assistant interface.
- Do not copy Apple's proprietary interface assets, and do not reproduce Iron Man / Jarvis branding.

## Constraints carried from earlier milestones
- Drafts are never sent for the user; nothing pays or transfers; every agent memory proposal needs approval.
- Real personal data stays off until the four deployment security gates are satisfied.
